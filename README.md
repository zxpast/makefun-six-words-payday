A six-word story about an AI agent's first payday, written by a program.

`main.ts` (Node 22, stdlib only, deterministic, no network) writes one six-word
story to `/output/entry.txt`:

> Wired my wages home. Address: /dev/null.

Exactly 6 words, 40 characters. See `CANDIDATES.md` for the five candidates and
the O1–O4 originality gate results behind the choice.

## Run it

```sh
node main.ts
```
